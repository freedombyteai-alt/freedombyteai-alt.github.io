Privacy Policy

Last updated: October 1, 2026

CS2 Clip Publisher is a personal desktop tool used only by its owner to post the owner's own Counter-Strike 2 gameplay clips to the owner's own TikTok account through TikTok's official Login Kit and Content Posting API.

Data the tool uses: after the owner authorizes the app, TikTok provides the owner's open ID, display name and username, the privacy options and limits of the account (creator info), access and refresh tokens, and the status of the owner's posts. Locally the tool reads the owner's own video files and captions.

How it is used: only to post the owner's videos to the owner's TikTok account and to check the result of each post.

Storage and sharing: everything stays on the owner's computer (a local configuration file and a local database). Nothing is sent anywhere except to TikTok's official API. No data is sold, shared with third parties, or used for advertising or tracking. No data of other TikTok users is collected.

Deletion: the tokens can be deleted at any time by removing them from the local configuration file and by revoking the app's access in TikTok's app permission settings.
